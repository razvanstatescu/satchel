Verify it yourself

  • No access keys on the accountnear account view-account-summary satchel.satchelhq.testnet network-config testnet-fastnear now
  • It has never signed a transactioncurl -s -X POST https://tx.test.fastnear.com/v0/account -H 'content-type: application/json' -d '{"account_id":"satchel.satchelhq.testnet","is_any_signer":true}'
  • Its oldest transaction is the birthcurl -s -X POST https://tx.test.fastnear.com/v0/account -H 'content-type: application/json' -d '{"account_id":"satchel.satchelhq.testnet","desc":false,"limit":1}'
