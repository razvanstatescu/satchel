How it works

  1. Mint a Satchel

    The NFT gets its own Bitcoin and Ethereum addresses. They're derived from the NFT, so they stay the same when it changes hands.

  2. Only the owner can sign

    To move coins, the owner asks the Satchel contract. It checks who owns the NFT, then asks NEAR's signer network for a signature.

  3. Give it or sell it

    The new owner gets everything inside. No bridge, no wrapped tokens, no seed phrase.
